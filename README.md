## Overview

Flutter Instagram Clone recreates Instagram's core screens as a Flutter UI project: the home feed with stories, search, posting, activity, profile, and direct messages.

> This is an educational UI clone and is not affiliated with Instagram or Meta.

## Features

- **Home feed** with stories and posts.
- **Story detail** view.
- **Search page** with an image grid.
- **Add post page.**
- **Favorites (activity) page.**
- **Account page,** with profile editing and post details.
- **Chat page.**
- **Custom bottom app bar** and bottom sheets.

## Getting Started

### Prerequisites

- Flutter SDK

### Installation

```bash
git clone https://github.com/RithyBondeth/Flutter-Instagram-Clone.git
cd Flutter-Instagram-Clone/assignment1_instagram_ui
flutter pub get
flutter run
```
